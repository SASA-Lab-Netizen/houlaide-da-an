# 后来的答案 — 参赛提交文件

## 项目简介

「后来的答案」是一个基于知乎生态的内容产品，核心功能是帮助用户追踪知乎回答的「后来」——那些年写下的回答，后来怎么样了。

产品分为两个部分：
1. **Campaign 引流页**（灵魂匹配局）— 知乎/公众号引流的沉浸式 H5 页面
2. **Demo 产品页** — 完整的 MVP 功能 Demo，含6大核心功能

## 如何查看

### 推荐方式：查看整合版（完整体验）

1. 打开 `3-整合版（Campaign+Demo）/` 文件夹
2. 用浏览器打开 `灵魂匹配局_水彩场景版.html`
3. 这就是完整体验入口：Campaign 引流页 → 跳转 → Demo 产品页

### 单独查看

- **只看引流页**：打开 `1-Campaign引流页/灵魂匹配局_水彩场景版.html`
- **只看产品页**：打开 `2-Demo产品页/index.html`

## 跳转链路说明

整合版中，Campaign 页和 Demo 页之间有桥接跳转：

| Campaign 页入口 | 跳转到 Demo 页 | 说明 |
|----------------|---------------|------|
| "看看他们的后来" 按钮 | 时间线功能页 | 查看真实故事的后来 |
| "遇见另一个故事" 按钮 | 匹配问卷 → 时间线 | 完成匹配后跳转 |
| "记录你的后来" 按钮 | 匹配问卷页 | 带redirect参数 |
| 发现同路人（卡片） | 匹配问卷 → 时间线 | 同上 |
| 看见他们的后来（卡片） | 时间线功能页 | 直达 |
| 追问更多细节（卡片） | 追问互动页 | 直达 |
| 写下你的后来（卡片） | 故事海报页 | 直达 |
| "进入完整产品"（右下角） | 产品首页 | 产品全貌入口 |

Demo 页中带有 `from=campaign` 参数时，顶部会显示「返回灵魂匹配局」浮动条，可一键返回 Campaign 页。

## 技术栈

- 纯静态 HTML + CSS + JavaScript
- 无后端依赖，无构建工具
- 浏览器直接打开即可运行

## 6大核心功能

1. **时间线追踪** — 记录故事的每一次「后来」
2. **同路人匹配** — AI帮你找到经历相似的人
3. **话题圈子** — 和同路人一起聊「后来」
4. **追问互动** — 追问你想知道的每一个后来
5. **故事海报** — AI提取金句生成分享海报
6. **智慧豆钱包** — 打赏答主，激励持续更新
